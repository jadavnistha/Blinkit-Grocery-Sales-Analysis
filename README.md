# Blinkit Grocery Product Analysis

## 📌 Project Overview

This project focuses on analyzing grocery sales data using SQL.
The analysis explores product information, pricing, item categories,
outlet characteristics, and sales performance.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- dBeaver

## 📊 Key Analysis Performed

- Product and item analysis
- Item price analysis
- Item fat content analysis
- Item type analysis
- Outlet analysis
- Sales analysis
- Aggregation using SUM, AVG, MIN and MAX
- GROUP BY and ORDER BY
- Filtering using WHERE, IN and BETWEEN
- Data sorting and categorization

## 🔍 SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- COUNT
- SUM
- AVG
- MIN
- MAX
- GROUP BY
- ORDER BY
- IN
- BETWEEN

## 📁 Project Files

- `Blinkit_Grocery_Product_Analysis.sql` — Contains all SQL queries used for the analysis.

## 🎯 Objective

The objective of this project is to practice SQL-based data analysis
and derive useful insights from grocery sales data.
